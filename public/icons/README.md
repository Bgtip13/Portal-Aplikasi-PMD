# Folder Logo Aplikasi

Taruh logo di folder ini dengan nama file **persis** sama dengan `slug` di
`src/data/apps.ts`. Format yang didukung (dicek berurutan): `.png`, `.svg`,
`.webp`, `.jpg`, `.jpeg`. Kalau logo belum ada, kartu otomatis memakai ikon
vektor bawaan.

| No | Aplikasi                | Nama file yang diharapkan |
| -- | ----------------------- | ------------------------- |
| 1  | Accurate Online         | `accurate.png`            |
| 2  | PMD Ecosystem 4.0 (APK) | `pmd-apk.png`             |
| 3  | PMD Ecosystem 4.0 (Web) | `pmd-web.png`             |
| 4  | Input Ekspedisi PMD     | `input-ekspedisi.png`     |
| 5  | View Laporan Ekspedisi  | `view-ekspedisi.png`      |
| 6  | Website PMD             | `website-pmd.png`         |
| 7  | Dashboard SPV           | `dashboard-spv.png`       |

Tips:

- Pakai logo persegi (1:1), ukuran 256x256 px sudah cukup (tampil 58 px).
  File yang terlalu besar membuat halaman lambat dimuat.
- Latar **transparan** paling bagus: ikon otomatis dipotong berbentuk
  rounded-square dan diberi bayangan warna aksen.
- Setelah menyalin file, cukup refresh browser. Tidak perlu ubah kode.
