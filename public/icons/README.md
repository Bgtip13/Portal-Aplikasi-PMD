# Folder Logo Aplikasi

Taruh logo di folder ini dengan nama file **persis** seperti daftar di bawah.
Format yang didukung (dicek berurutan): `.png`, `.svg`, `.webp`, `.jpg`, `.jpeg`.
Kalau sebuah logo belum ada, kartu otomatis memakai ikon gradien + emoji.

| No | Aplikasi                     | Nama file yang diharapkan |
| -- | ---------------------------- | ------------------------- |
| 1  | Accurate Online              | `accurate.png`            |
| 2  | PMD Ecosystem 4.0 (APK)      | `pmd-apk.png`             |
| 3  | PMD Ecosystem 4.0 (Web)      | `pmd-web.png`             |
| 4  | Laporan Ekspedisi PMD        | `laporan-ekspedisi.png`   |
| 5  | Website PMD                  | `website-pmd.png`         |
| 6  | Dashboard SPV                | `dashboard-spv.png`       |

Tips:

- Gunakan logo persegi (1:1) atau transparan, ukuran ideal 256×256 px atau 512×512 px.
- Logo akan otomatis menyesuaikan ukuran kotak ikon, jadi tidak perlu pas.
- Setelah menyalin file, cukup refresh browser — tidak perlu ubah kode.
